# Sistem Pelaporan Kerusakan Fasilitas Sekolah
Ujian Praktik Individu DTP Software Developer 2026.

## Deskripsi Singkat
Aplikasi berbasis web untuk mencatat, memantau, memperbarui, dan menghapus data laporan kerusakan fasilitas sekolah secara digital menggantikan pencatatan manual.

## Kebutuhan Aplikasi
- Web Server (XAMPP / Laragon) dengan PHP versi 8.0 ke atas
- Database MySQL / MariaDB
- Web Browser (Chrome / Edge / Firefox)

## Cara Menjalankan Website
1. Pindahkan folder project ke dalam direktori `htdocs` (jika menggunakan XAMPP).
2. Nyalakan modul **Apache** dan **MySQL** pada XAMPP Control Panel.
3. Buka `http://localhost/phpmyadmin`, buat database bernama `db_laporan_fasilitas`, lalu import file `database.sql`.
4. Buka browser dan akses `http://localhost/nama-folder-kamu/index.php`.
